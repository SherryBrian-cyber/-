# 公众号排版校对助手

一个可本地运行的公众号排版程序：上传 `.docx` 后自动进行段落分类和可读性优化，并支持人工删减、修改、补充，最后导出 Markdown。

## 功能

- 上传 Word（`.docx`）文档自动解析。
- 自动识别标题 / 小标题 / 正文 / 列表。
- 自动拆分过长正文，提升手机端阅读体验。
- 提供清晰的可视化编辑界面，可逐段手动修改和删除。
- 支持新增段落。
- 导出为 Markdown，便于粘贴到公众号编辑器继续微调。

## 快速开始

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

启动后浏览器访问 `http://localhost:8501`。

## 使用流程

1. 上传 Word 文档。
2. 程序自动排版并显示段落编辑卡片。
3. 手动调整段落类型和内容，删除不需要的段落，必要时新增段落。
4. 点击“导出 Markdown”下载结果。

## 说明

- 当前版本仅支持 `.docx`（不支持老版 `.doc`）。
- 自动分类是启发式规则，复杂文稿建议人工复核。
