# AI 大模型科技树图谱（交互版）

一个参考 O-DataMap 思路构建的可交互 AI 大模型科技树应用：
- 左侧用 **TreeMap** 展示“模型能力分支地图”；
- 右侧按分支实时拉取 **arXiv 最新论文**，用于跟踪前沿进展与发现。

## 功能亮点

- 🗺️ **科技树可交互**：支持点击下钻与返回上层，像地图一样查看 AI 领域结构。
- 🔍 **分支级实时追踪**：按分支关键词调用 arXiv API，展示最新论文。
- 🧭 **可扩展分支体系**：可按团队关注方向新增领域与关键词。
- ⚡ **手动即时刷新**：点击按钮清空缓存并重新拉取最新数据。

## 快速开始

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

启动后访问 `http://localhost:8501`。

## 典型使用方式

1. 在左侧科技树中观察领域全貌，点击下钻到某一细分方向。
2. 在右侧选择具体分支（如“Agent / 工具调用与规划”）。
3. 查看该分支最新论文列表、摘要与原文链接。
4. 每日点击“立即刷新”持续跟踪前沿变化。

## 后续可扩展方向

- 增加更多数据源：OpenReview、Papers with Code、Hugging Face。
- 增加趋势统计：分支周增量、热度变化、关键词演化。
