# AI 大模型科技树图谱（论文实时填充）

一个参考 O-DataMap 思路构建的可交互 AI 大模型科技树应用：
- 左侧用 **TreeMap** 展示科技树，并在每个叶子节点显示该分支最新论文标题；
- 右侧显示分支真实论文详情（时间、作者、摘要、原文链接）；
- 底部汇总“跨分支最新发现”列表，便于快速扫描前沿动态。

## 功能亮点

- 🗺️ **科技树可交互**：支持点击下钻与返回上层，像地图一样浏览。
- 📄 **节点内含真实论文**：每个分支节点填充 arXiv 最新论文标题。
- 🔍 **分支级实时追踪**：按关键词拉取最新论文并展示详情。
- 🌍 **全局最新发现面板**：跨分支按时间汇总最新论文。
- ⚡ **缓存 + 刷新机制**：默认 20 分钟缓存，可一键强制刷新。

## 快速开始

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

启动后访问 `http://localhost:8501`。

## 使用流程

1. 先在左侧查看科技树全貌，悬浮叶子节点可看该分支 Top3 标题。
2. 在右侧选择分支，查看对应真实论文列表与摘要。
3. 在底部“全局最新发现”快速扫描跨分支动态。
4. 使用侧边栏调整每个分支拉取数量并按需强制刷新。
